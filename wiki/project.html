Project Objectives

This project demonstrates a 5G NR OpenAirInterface testbed implementing:

  • CU/DU split architecture following 3GPP specifications
  • Flexible F1 transport over Ethernet, Wi-Fi GRE, or experimental Quectel wireless backhaul
  • One-CU/two-DU target topology with separate donor and access radio roles
  • Public Warning System (PWS) broadcast via SIB8
  • Commercial UE connectivity and service validation

Project Scope

In Scope

  • A separate single-host reference and reproducible CU/DU split deployments
  • F1 interface implementation and transport options
  • PWS/SIB8 broadcast functionality
  • USRP B210 SDR integration
  • Measurement and performance evaluation

Out of Scope

  • Commercial-grade reliability certifications
  • Large-scale network deployments
  • Production core network features

Key References

  • OpenAirInterface: Open-source 5G/4G implementation (openairinterface.org)
  • 3GPP TS 38.470: F1 interface specifications
  • 3GPP TS 38.331: RRC specifications including SIB8
  • Ettus USRP B210: SDR hardware documentation
