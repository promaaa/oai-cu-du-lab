Computing Hardware

The lab uses dedicated computing hosts for different functions:

serber-firecell

  • Runs 5GC (core network) and CU functions
  • Hosts the single shared CU in split workflows
  • Controls the donor-side deployment path

serber-minipc

  • Runs the access DU for local access/fronthaul
  • Hosts USRP B210 access radio
  • Quectel modem integration for wireless backhaul

USRP B210

Ettus Research Software-Defined Radio platform used as the access radio:

  • Frequency Range: 70 MHz - 6 GHz
  • Bandwidth: Up to 56 MHz instantaneous
  • Duplex: Full duplex (2x2 MIMO)
  • Interface: USB 3.0
  • Lab Band: n78 (3.3-3.8 GHz)

Quectel RM500Q-GL

5G modem module providing wireless backhaul capability:

  • Form Factor: M.2 module
  • 5G Bands: Sub-6 GHz support
  • Interface: USB/PCIe with AT command control
  • Use Case: Carries the access-DU F1 overlay after attaching to the independent donor-DU cell
  • Integration: USB-connected to serber-minipc

UE Devices

Commercial smartphones used for testing:

Nothing Phone

  • Primary test UE for attach and service validation
  • Android-based with 5G capability
  • Used for PWS/SIB8 message reception testing

Additional UEs

  • Various Android devices with 5G support
  • Qualcomm Snapdragon-based devices preferred for OAI compatibility
