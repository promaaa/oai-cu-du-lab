Radio ownership

The lab has two interchangeable B210 radios. Discover the radio attached to every selected host before launch; the operator console reads its serial live and generates the runtime configuration. For Quectel/WireGuard, one B210 provides the Firecell donor cell and the other provides the access cell.

A radio host should expose exactly one B210 through UHD. If more than one is attached, use the approved per-host serial override rather than relying on USB enumeration order.

Quectel modem

The RM500Q-GL is attached to the selected access-DU side for the Quectel profile. Its packet session provides the outer path for wg-quectel-f1; the modem must camp on the independent Firecell donor cell, not on the access cell it backhauls.

Warning: management addresses and physical connections drift. Discover them before every run.
