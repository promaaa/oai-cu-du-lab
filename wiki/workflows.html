Reference Deployment

A single-host gNB is retained only as a separate performance reference. It is not the architecture of the CU/DU wireless-backhaul workflow.

Components

  • 5GC (AMF, SMF, UPF, etc.)
  • Monolithic gNB (CU+DU functions combined)
  • USRP B210 access radio

Use Case

Establish comparison measurements for throughput, latency, and scheduler performance. The Ethernet split remains the rollback baseline.

CU/DU over Ethernet

Split architecture with F1 interface transported over wired Ethernet. This is the primary and most stable deployment mode.

Components

  • 5GC on serber-firecell
  • CU on serber-firecell
  • DU on serber-minipc
  • USRP B210 on serber-minipc
  • Ethernet for F1 transport

Use Case

Reproducible split deployment and rollback target for all experimental backhaul work.

CU/DU over Quectel

The target wireless-backhaul workflow keeps one CU and uses two DUs. It is experimental and must not be reported as working without a fresh evidence-gated run.

Components

  • 5GC and one shared CU on serber-firecell
  • One donor DU providing the independent Quectel serving cell
  • Quectel RM500Q-GL attached to the donor-DU cell
  • One access DU on serber-minipc with USRP B210
  • Access-DU F1-C/F1-U carried through WireGuard over the Quectel PDU session

PASS gate

Require sanitized proof of both F1 associations, Quectel registration and IP service, F1-C/F1-U on the intended tunnel, phone attach/internet or PWS observation on the access cell, and successful Ethernet rollback.

CU/DU over Wi-Fi

Split architecture with F1 interface transported over Wi-Fi using GRE tunnels. Useful for wireless F1 backhaul experiments.

Components

  • 5GC and CU on serber-firecell
  • DU on serber-minipc
  • Wi-Fi network with GRE tunnel for F1
  • USRP B210 access radio

Use Case

Wireless F1 transport testing, useful when Ethernet connectivity is not available between CU and DU locations.

PWS/SIB8 Broadcast

Public Warning System workflow demonstrating ETWS message broadcast capability using SIB8.

Components

  • 5GC with PWS capability
  • CU for warning coordination
  • DU for radio broadcast
  • USRP B210 for over-the-air transmission

Use Case

Emergency alert system demonstration, validating broadcast message delivery to connected UEs.
