Project Overview

This project develops a 5G NR OpenAirInterface (OAI) testbed around a reproducible CU/DU split. The verified and experimental paths are kept distinct:

  • Ethernet CU/DU with SIB8 as the canonical rollback baseline
  • Wi-Fi GRE as a verified wireless F1 transport candidate
  • A target Quectel topology with one CU, one donor DU, and one access DU
  • System Information Block Type 8 (SIB8) and Public Warning System (PWS) broadcast
  • Commercial UE attach, service, throughput, and PWS validation
Evidence status

The Quectel F1 path remains experimental. It is not a PASS until sanitized evidence proves both DUs, the modem path, F1-C/F1-U, phone service, and rollback.

Key Features

CU/DU Split

Central Unit and Distributed Unit separated per 3GPP specifications, connected via F1 interface.

PWS/SIB8

Public Warning System broadcasts using SIB8 for earthquake and tsunami alerts.

Flexible Transport

Ethernet is the rollback baseline, Wi-Fi GRE is verified, and Quectel is the experimental wireless-backhaul target.

USRP Radio

Ettus USRP B210 provides local access radio with SDR capabilities.

Architecture Summary

The target wireless-backhaul system consists of:

  • 5GC: Core network (AMF, SMF, UPF, etc.)
  • One CU: shared F1 termination and higher-layer control on serber-firecell
  • Donor DU: provides the independent donor cell used by the Quectel modem
  • Access DU: runs on serber-minipc with the B210 for local access/fronthaul
  • Transport: the access-DU F1 path is carried over WireGuard and the Quectel PDU session
