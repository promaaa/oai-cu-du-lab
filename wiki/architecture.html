Architecture Overview

The OAI CU/DU Lab implements a 5G NR testbed based on OpenAirInterface. The backhaul target uses one shared CU and two distinct DUs: a donor DU for the Quectel serving cell and an access DU on serber-minipc for the local radio path.

CU/DU Split Architecture

The architecture separates higher-layer control from two radio-facing roles:

Central Unit (CU)

  • Radio Resource Control (RRC)
  • Packet Data Convergence Protocol (PDCP)
  • Service Data Adaptation Protocol (SDAP)
  • F1 termination point
  • PWS/SIB8 coordination

Donor DU

  • Connects to the shared CU over its own F1 path
  • Provides the independent donor cell used by the Quectel modem
  • Must remain independent of the access cell to avoid a circular backhaul dependency

Access DU on serber-minipc

  • Radio Link Control (RLC)
  • Medium Access Control (MAC)
  • Physical Layer (PHY)
  • Scheduler
  • USRP B210 local access radio
  • F1 carried through WireGuard over the Quectel PDU session in the target backhaul path

F1 Interface

The F1 interface connects the CU and DU over IP-based transport. Key characteristics:

  • Logical interface defined by 3GPP TS 38.470
  • Supports F1-C (control plane) and F1-U (user plane)
  • Transport options: Ethernet rollback baseline, verified Wi-Fi GRE, and experimental Quectel wireless backhaul
  • Enables flexible deployment across multiple physical machines

PWS/SIB8 Broadcast

Public Warning System implementation using SIB8:

  • SIB8 carries Earthquake and Tsunami Warning System (ETWS) information
  • Primary Notification: Immediate safety alert
  • Secondary Notification: Additional safety information
  • Broadcast over NR radio to connected UEs

Lab Topology

The target Quectel deployment includes:

  • serber-firecell: Hosts the 5GC and the single shared CU
  • Donor DU: Runs the independent donor radio for the Quectel modem and connects to the shared CU
  • serber-minipc: Hosts the access DU and USRP B210 local access radio
  • USRP B210: SDR platform for RF transmission (n78 band)
  • Quectel RM500Q-GL: Attaches to the donor-DU cell and carries the access-DU F1 overlay
  • Commercial UE: Nothing Phone for attach and service testing
5GC + one CU (serber-firecell)
  ├── F1 ── donor DU ── RF ── Quectel modem
  └── F1 over WireGuard/Quectel ── access DU (serber-minipc) ── B210 ── phone
