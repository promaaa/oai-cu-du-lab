Architecture

From OAI CU/DU Lab

Canonical target

Firecell hosts one OAI 5GC and one shared CU. An independent donor DU provides the donor cell used only by the Quectel modem. A separate access DU provides the local cell used by the commercial phone.

Firecell: OAI 5GC + shared CU
  ├─ F1 → donor DU → donor cell → Quectel modem
  └─ F1 → access DU → B210 access cell → Nothing Phone
             ↑
      F1 carried through WireGuard over Quectel
Compatibility mode: the caged workflow can also use the monolithic donor path for focused modem and backhaul testing.

SIB8/PWS

The CU handles warning content and the F1AP request. The DU schedules the resulting system information. Network logs and phone-visible warning reception are different acceptance gates.

Rollback baseline

MiniPC Ethernet CU/DU with SIB8 is the canonical rollback. The monolithic deployment remains a separate reference.
